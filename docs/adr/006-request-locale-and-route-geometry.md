# ADR 006: 요청별 언어와 출처가 있는 노선 형상

날짜: 2026-09-20 · 상태: 적용

## 언어

ADR 002의 react-i18next, URL prefix 없는 구조는 유지한다. 다만 브라우저 감지기의 전역 초기화와 고정 일본어 SSR은 쿠키를 덮어쓰고 MDX/RSC를 다른 언어로 남기는 문제가 있어 폐기한다.

`proxy.ts`가 `lang` 쿼리, `i18next` 쿠키, `Accept-Language`, 기본값 `ja` 순으로 결정한다. 요청 헤더를 덮어써 RSC에 전달하고 root layout은 HTML 언어 및 요청별 i18n 인스턴스의 초기값을 공유한다. 언어 버튼은 쿠키와 URL을 변경해 서버 본문도 다시 렌더링한다. 이로 인해 언어별 페이지는 동적 SSR을 사용한다.

## 경로

정류장 좌표와 운행 경로는 서로 다른 데이터다. 정류장 배열을 직선으로 연결하면 산길·왕복·순환 구간을 표현할 수 없다. `routes/*.json` 안에 출처·확인일·방식·코스별 `geometry`를 보관한다. `getRouteCoordinates`는 이 형상을 반환하며 지도와 버스 데모가 공유한다.

- 시티뷰·야경: 교통국 공식 노선도 구간 좌표.
- 아일랜드뷰: GTFS에는 shapes.txt가 없어 OSM 도로 형상을 공식 PDF와 대조한 참고 경로. 공식 GPS 궤적·현장 실측으로 표현하지 않는다. 일반 자동차 경로가 우회하는 산길은 공개 OSM way를 연결한 출처 스냅샷으로 보완한다.
- 검증 상태: 좌표 출처 확인과 현장 검증은 독립적이다. 공식 GTFS로 교체해도 `lastFieldVerifiedAt`을 새로 기록하지 않는다.

CI는 좌표·시간표 원본 대조, A/B 구분, 산길 포함, 형상 연결 및 언어·모바일 회귀를 검증한다. 새로운 원본을 가져온 뒤 실제 지도와 공식 코스의 시각 대조는 여전히 필요하다.

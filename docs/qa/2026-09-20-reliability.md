# 신뢰성 개선 결과 — 2026-09-20

| 우선순위 | 분석에서 확인한 문제 | 적용한 개선 |
|---|---|---|
| 1 | 미실측 정류장에도 GPS 검증 배지가 표시됨 | 근사치·공식 출처 확인·현장 검증의 세 상태로 분리. 지도 오류 배지와도 독립적으로 표시 |
| 2 | 모바일 상세에서 목록으로 돌아가거나 검색하기 어려움 | 목록 복귀 버튼, 검색·필터 시 선택 해제, 바텀시트 손잡이와 내용 스크롤 분리. 390px 상단 메뉴 줄바꿈과 상세 패널 뒤로 마커가 가려지는 문제도 보정 |

| 4 | 아일랜드뷰 근사 좌표 5곳·왕복 정류장 중복·명칭 및 시간표 문제 | 공식 GTFS 승강장 12곳 반영, 7/9번 방향 구분, 12번 위치·명칭 교정, A/B 시간표 및 야경 요금 대조 |
| 5 | 정류장 간 직선 경로, 사용자 시간대에 따른 운행일 차이, 지도 초기화 문제 | 공식 시티뷰/야경 도로 형상, OSM 기반 아일랜드뷰 A/B 참고 경로, JST 운행일, 직접 링크 초기 중심과 스타일 재적용 보정 |
| 6 | 자동 회귀·CI 부재와 린트·보안 문제 | Vitest·Playwright·GitHub Actions 추가, 린트 경고 해소, Next.js/NextAuth 및 취약 전이 의존성 갱신 |

## 실행한 자동 검증

최종 코드 기준 로컬 실행 결과:

| 검사 | 결과 |
|---|---|
| `npm run lint` | 오류 0, 경고 0 |
| `npm test` | 3개 파일, 20개 테스트 통과 |
| `npm run build` | Next.js 16.3.5 / webpack 프로덕션 빌드 성공, PWA service worker 생성 |

제외된 테스트는 데스크톱 프로젝트의 모바일 바텀시트 전용 흐름이며, 모바일 프로젝트에서는 실행·통과했다. 모바일 환경은 Chromium 기반 기기 에뮬레이션이며 실제 iOS Safari 검증을 의미하지 않는다.

단위 검사는 39개 정류장 ID/관련 시간표, 공식 아일랜드뷰 좌표, 왕복 승강장 구분, A/B 형상·산길·연결, 균등/불규칙 배차, 언어 우선순위, JST 날짜 경계 및 데이터/번역 무결성을 포함한다. 브라우저 회귀는 3개 언어 전환·새로고침·MDX, 동시 요청 언어 격리, 검증 배지, 모바일 탐색과 상단 배치, 비로그인 관리자 차단과 잘못된 URL의 404를 검사한다.

## 실제 지도·원본 확인

- 공식 GTFS ZIP의 버전·기간·해시와 승강장 ID를 대조했다. 시티뷰의 기존 현장 좌표는 자동 덮어쓰지 않았다.
- 교통국 공식 아일랜드뷰 PDF의 두 페이지를 이미지로 렌더링하여 A/B 코스와 시간표·명칭 안내를 확인했다.
- 실제 Mapbox 지도를 열어 아일랜드뷰 A/B 도로 형상을 공식 코스와 비교했다. 처음 생성된 자동차 최단 경로의 북쪽 우회를 발견해 10→11번 산길을 공개 OSM way 형상으로 보정했다.
- 모바일 390×844와 데스크톱 화면에서 코스 선택, 지도 스타일 전환, 언어 전환 및 노선 레이어 표시를 확인했다.
- 새 로컬 포트의 최종 빌드에서 모바일 직접 링크의 선택 마커가 상세 패널 위에 보이는 것을 확인했다. 스타일에 GeoJSON 소스를 추가한 직후 로딩 상태가 다시 바뀌어 선택 처리가 누락되는 조건도 보정했다.

출처, 라이선스, 좌표 차이, 재현 명령은 [데이터 출처](../data-sources.md), 운영 절차는 [데이터 갱신 가이드](../data-update-guide.md), 설계 근거는 [ADR 006](../adr/006-request-locale-and-route-geometry.md)에 기록했다.

## 검증 범위의 한계

- 이번 작업에서 새 현장 GPS 실측은 하지 않았다. 시티뷰의 2026-05-31 실측일은 기존 기록이며, 야경·아일랜드뷰를 현장 검증으로 표시하지 않는다.
- 아일랜드뷰 도로 형상은 공식 운행 GPS 궤적이 아닌 참고 경로다. OSM 도로 중심선과 실제 승강장 간 차이가 있을 수 있다.
- 야경의 날짜·계절별 시간표를 합쳐 일반 출발 시각으로 노출하지 않는다. JST 기반 정기 운행 표시는 임시 휴무·증편을 실시간 반영하지 않는다.
- 자동 UI 검사에서는 외부 지도·분석 요청과 service worker를 차단한다. PWA 설치 후 완전 오프라인 동작, 실제 단말 위치 권한·도보 경로, Google OAuth 실로그인은 이번 회귀에서 검증하지 않았다.
- GitHub Actions 설정은 작성했지만 아직 푸시하지 않아 원격 실행 결과는 없다. 운영 배포도 수행하지 않았다.
- 기존 `tmp/` 파일은 그대로 보존했다. 비밀 환경 변수는 문서·테스트 원본에 복사하지 않았다.

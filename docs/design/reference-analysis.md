## 1. ひらやすみ × 杉並区 (1번 레퍼런스)

### 1.1 구조
1. **로딩**: 종이 질감 위로 캐릭터가 달리는 로더
2. **상단 걸린 간판**: `今日の杉並区 9月21日(月) あめ`. 나무 간판에 날짜와 날씨를 **실시간** 표시
3. **히어로**: 작품 로고 × 구 로고 락업, 손글씨 `コラボキャンペーン` + 붓 밑줄, 오른쪽에 캐릭터와 오토바이, 가장자리에 거대한 세로 영문 `HIRAYASUMI × SUGINAMI CITY`
4. **세로 레일**: 왼쪽에 SHARE(LINE, X)와 NEWS 세로 티커
5. **ABOUT**: 손글씨 라벨 + 초록 붓 밑줄, 손글씨 제목, 본문 줄마다 초록 점선 구분, 핵심 구절에 연두색 형광펜
6. **폴라로이드 01~05**: 번호(손글씨 초록), 손글씨 캡션, 동그라미 친 장소 태그(`たなばたまつり`) + 손그림 화살표, `まだまだつづきます…!`
7. **초록 섹션**: 왼쪽 고정 코르크보드 목차(압정, 번호 나무 태그), 오른쪽 캠페인 카드. 카드 구성은 거친 가장자리 + 네 모서리 압정 + 연두 북마크 리본 `CAMPAIGN 01` + 카테고리 + 손글씨 제목 + 본문 + 테이프 폴라로이드 + 점선 + **정보 바**(마스코트 아이콘 + `開催日時` / `場所`) + Google Map 링크
8. **푸터**: 로고 락업, 작품·구 공식 SNS(둥근 사각 초록 버튼), 거대한 영문 마퀴, 저작권

### 1.2 값
- **색**: 종이 `#F3E9CD`·`#F7F1DE`, 주색 초록 `#009B63`(화면상 구 로고와 같은 초록), 연두 `#DAE243`/`#CDDC01`(형광펜·리본), 황토 `#B77F36`(간판), 빨강 `#DF1616`(포인트), 글자 `#000`/`#101010`
- **서체 굵기**: 700 / 300 / 900. 손글씨 제목은 굵게, 본문은 가늘게
- **그림자**: `0 .14vw .69vw #0000000F`. 아주 옅은 종이 그림자 하나
- **기울기**: -9°(도장), -2.5~2°(종이), -16~8°(시작 상태)
- **모션**
  - 이징 `cubic-bezier(.22,1,.36,1)`
  - 도장: `rotate(-16deg) scale(2.1)` → `rotate(-8deg) scale(.94)` → `rotate(-9deg) scale(1)`
  - 히어로: 표제 옆에서 미끄러져 들어옴(0.9s), 사진 블러 해제(0.7s), 간판·로고 위에서 떨어짐(0.6s)
  - 손그림 떨림: 0.02em 이내 이동 + 0.3° 회전 반복
  - 오토바이 흔들림: 1px 이내
- **거친 가장자리**: `feTurbulence(baseFrequency .09, numOctaves 4) + feDisplacementMap(scale 5)`. 종이 조각을 가위로 자른 느낌

### 1.3 채택한 것
- 크림 종이, 폴라로이드와 테이프, 손글씨 동그라미·화살표, 도장 모션, 거친 가장자리 필터, 이징 값 → 토큰과 `scrapbook.module.css`로 흡수
- **번호 카드 + 정보 바** 구성 → 정류장·이벤트 카드 표준 패턴(design-system §6.3)
- 로고 락업(`작품 × 구`) → 채택 뒤 `서비스 × 가고시마시` 자리
- 1440/375 기준, 1023px 전환점

### 1.4 채택하지 않은 것
- **캐릭터 중심 구성**: 우리에게는 IP가 없습니다. 정류장 표지판·승차권 같은 사물로 대체합니다.
- **웹폰트**: 오프라인 원칙 때문에 시스템 폰트로 대체합니다(design-system §10의 열린 결정 참고).
- **로딩 화면**: 버스를 기다리는 사용자에게는 지연이 곧 비용입니다.
- **초록 글자**: 크림 바탕에서 대비 2.96:1로 AA에 미달합니다. 파트너 색은 큰 글씨·장식에만 씁니다.

## 2. 佐賀市へ #連れ帰省 (보조 레퍼런스)

### 2.1 구조
1. 상단 마퀴 띠 `さがそう！佐賀市の あたりまえハッピー` + X·Instagram + 메뉴
2. **히어로 = 승차권**: `DESTINATION : SAGA CITY` 티켓. 사선 줄무늬 테두리, 절취선 너머 오른쪽 스텁에 신청 기간 `6.17 ▼ 7.15`, 체크박스 `□友達 □同僚 □パートナー □家族`. 세로쓰기 `佐賀市へ`, 손글씨풍 파란 표제, 톱니 원형 배지 `最大5万円`
3. 개념 설명 (가운데 정렬, 행간 넓게) + 흰 카드 `#連れ帰省のススメ`(일러스트 + 번호 1~3)
4. 체험 영상 2편
5. 해시태그 마퀴 `#都会の友達を #パートナーを …`
6. **혜택 카드 3열**: 색 카드 + 카드 위로 튀어나온 사진 오브젝트(비행기·신칸센, 초밥, 스마트폰) + 큰 숫자 `30,000円`
7. 개요 정의 표(좌 라벨 / 우 값, 가로 괘선)
8. 참가 흐름 4단계, 신청 폼, FAQ(아코디언), 응모 규약(아코디언 목차)
9. SNS 공유 카드(겹친 종이 + X·Facebook·LINE)
10. 푸터: 관련 사이트 배너, **佐賀市観光振興課 + 주소 + 전화**, 이용약관·개인정보, © Saga City, 쿠키 동의 배너

### 2.2 값
- **색**: 바탕 연분홍 `#FFE2DA`, 코랄 `#F76C4B`/`#CF5738`, 하늘 `#B3DAF1`/`#BBD9E3`, 노랑 `#F5D875`, 초록 `#617D45`, 파랑 `#007AFF`(표제), 글자 `#4D4D4D`/`#373334`(순수 검정 없음), 푸터 모브 `#63545C`
- **글자 대비**: `#4D4D4D` / `#FFE2DA` = 6.9:1
- **그림자**: 흐림 없는 **오프셋 그림자** `.42vw .42vw #4D4D4D`. 스티커와 겹친 종이 느낌
- **반경**: 12px(카드), 50%(원형 버튼)
- **행간**: 1.8 / 2.0
- **폰트 처리**: YakuHanRP로 약물(、。「」)을 반각으로 줄여 일본어 제목의 들쭉날쭉함 제거
- **호버**: `(hover: hover)` / `(hover: none)`을 나눠 터치 기기에서 호버 효과 제거

### 2.3 채택한 것
- **오프셋 그림자** → `--shadow-offset`(주요 버튼·스티커)
- **정의 표**와 **혜택 카드 3열** → 운행 정보·요금 안내 패턴
- **승차권 모티프** → 버스 서비스에 가장 자연스러운 소재. 다음 개편 때 히어로나 배너에 사용 후보
- **운영 주체 푸터**(課名·주소·전화·©) → 채택 뒤 푸터 구성의 기준
- 쿠키·개인정보·규약을 갖춘 공공 사이트의 기본 구성 → design-system §8

### 2.4 채택하지 않은 것
- 분홍·코랄 중심의 팝 팔레트: 우리의 크림·먹·화산재 톤과 충돌합니다. 오프셋 그림자 기법만 가져옵니다.
- 3D 인형 오브젝트, 열기구 등 장식 과다: 정보 화면(지도)과의 일관성이 떨어집니다.

## 3. 두 사이트에서 읽히는 지자체 사이트의 공통점

1. **운영 주체가 분명합니다.** 로고 락업, 課名, 주소, 전화, ©. 누가 책임지는 정보인지가 첫 화면과 푸터에 있습니다.
2. **"현지의 일상"을 소재로 삼습니다.** 히라야스미는 작품 속 동네, 사가시는 "あたりまえ(당연한 일상)". 우리 서비스에서는 **"현지 사람에게는 당연한 정류장 위치를 여행자는 모른다"**는 이야기가 같은 결입니다.
3. **손으로 만든 질감.** 종이, 손글씨, 스티커, 테이프. 행정 사이트의 딱딱함을 풀어 주는 공통 장치입니다.
4. **SNS는 LINE을 포함합니다.**
5. **SP 우선.** 두 곳 모두 SP 전용 레이아웃·애니메이션을 따로 둡니다(`sp-*` 키프레임, `/375` 계산).
6. **정보 블록은 정형입니다.** 장식은 자유롭지만 일시·장소·요금·신청 기간은 표나 정보 바로 반듯하게 제공합니다. design-system의 원칙 2("장식은 가장자리에, 정보는 똑바로")의 근거입니다.

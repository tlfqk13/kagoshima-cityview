## 2. 두 사이트의 공통 문법 (우리가 가져올 것)
1. **색 하나.** 브랜드색 1 + 흰색 + 연회색 띠 + 진회색 글자. 두 번째 색은 없다.
2. **둥근 것.** 카드 radius 16〜24px, 알약 버튼, 원형 이미지, 곡선 섹션 경계.
3. **짧고 구어체인 큰 제목.** 「ぶっちゃけどうだった?」「ここでした」. 질문형이 많다.
4. **이야기 순서.** 곤란함(말풍선) → 증거(큰 숫자) → 결론 → CTA. 설명보다 숫자가 먼저 눈에 들어온다.
5. **큰 숫자가 그림이다.** 도넛 차트·대형 퍼센트.
6. **신뢰 각주.** 조사 기간·대상·방법을 작은 글씨로 끝에 붙인다.
7. **일러스트가 주인공.** 사진 대신 일러스트(3D). 우리는 저작권 있는 엽서 일러스트(종이 콜라주)를 쓴다 — 디자인 시스템 원칙 4(캐릭터 대신 사물).
8. **한 문단 30〜45자, 한 화면에 메시지 하나.**

## 3. MAKORO에 적용
- **정체성 한 줄:** 「つくって、置いて、動かす。」 — 旅行者向けの交通案内をつくり、現地で確かめ、運営まで行う開発会社.
- **색(2026-10-03 교체, 사장님 지시 "레퍼런스가 디자인 원천"):** Brother SDGs STORY의 CSS에서 추출한 값을 그대로 쓴다. 주색 파랑 `#0F2EA0`, 글자 `#222`/`#333`, 보조 글자 `#666`, 띠 `#F0F2F4`·`#F1F1EF`, 선 `#D3D3D3`, 파스텔 포인트 4색 산호 `#E98788`·금 `#DCA556`·연보라 `#748CDB`·민트 `#6CC8B2`(원형 배경은 각 색의 연한 틴트). KABU&의 빨강 `#FF001A`는 제품 브랜드색이라 쓰지 않고 레이아웃 문법(말풍선·큰 숫자·CTA 띠)만 가져온다. 가고시마 갈색은 회사 사이트에서 쓰지 않는다.
- **형태:** 레퍼런스 값 그대로 — 원형 아이콘 `border-radius:50%`(Brother CSS 72회), 알약 버튼 30px, 카드 10px, 섹션 하단 곡선.
- **아이콘·이미지:** 레퍼런스 둘 다 3D 일러스트가 주인공. 타사 그림은 못 쓰므로 같은 계열에서 가장 널리 쓰이는 **Microsoft Fluent Emoji 3D(MIT)** 256px PNG를 `sites/makoro/img/3d/`에 두고 파스텔 원 안에 넣는다(2026-10-03 3dicons에서 교체, 사장님 지시 '더 대중적인 것'). 푸터에 출처 표기. 가고시마 엽서 일러스트는 자사 서비스 카드(og.jpg)에만.
- **서체:** **Noto Sans JP**(일본 웹 랜딩에서 가장 많이 쓰는 웹폰트, 2026-10-03 사장님 지시) + 대체 ヒラギノ角ゴ・游ゴシック・メイリオ. 가고시마 사이트의 Zen Maru Gothic은 서비스 전용으로 두고 회사 사이트는 표준 고딕. 정적 사이트라 Google Fonts 링크 사용, 추후 자체 호스팅.
- **구성(위에서부터):**
  1. 히어로: 엽서 일러스트 + 「つくって、置いて、動かす。」 + 한 줄 설명 + 알약 버튼 2(開発のご相談 / 鹿児島の実例を見る). 하단 곡선.
  2. 곤란함: 말풍선 4 — 외주를 맡기는 일본 기업의 흔한 걱정(作ったあと誰が面倒を見る／多言語は翻訳だけで足りる？／データの出どころ／小さく始めたい).
  3. 증거: 가고시마 실례의 숫자 — 20停留所 현지 GPS, 8/20 Googleマップずれ(도넛 40%), 4言語, 31施設 전용 QR, 広告0. 모두 실제 데이터(감사 2026-07-20, 실측 2026-05-31).
  4. 할 수 있는 일(開発・制作) 카드 3 + 진행 4 STEP.
  5. 만든 사람·이유 한 문단(天文館).
  6. CTA 띠(브랜드색) → 会社概要 → 각주(데이터 출처·조사일).
- **하지 않는 것:** 두 번째 색, 사진 스톡, 지어낸 숫자·고객 후기, 「無限」「何でも」 같은 과장, 외주 비중이 가고시마보다 커 보이는 배치.

## 5. 모션 (레퍼런스 3: 三菱鉛筆 JETSTREAM Lite 특설 https://www.mpuni.co.jp/special/lite24S/ — 2026-10-03 분석)
측정: jQuery + inview.js + Rellax. 라이브러리 없이 같은 문법을 바닐라 JS/CSS로 옮겼다(`sites/makoro/index.html` 하단 script).
| 레퍼런스 기법 | 측정값 | 우리 구현 |
|---|---|---|
| 뷰포트 진입 시 등장(`.inview`→`.is-show`) | transition 1.2s, translate3d → 0, opacity 0→1 | `[data-reveal]`(up/left/right/scale) 1.1s `cubic-bezier(.22,1,.36,1)`, IntersectionObserver threshold 0.08 |
| 형제 순차 등장 | `:nth-child(n)` 0.1s 간격 | 부모 `[data-stagger]` → 자식 0.1s 간격, 히어로는 `data-delay` 0.12s 단위 |
| 고정 히어로 페이드(`.s-mv.is-disable`) | 스크롤 10px부터 opacity 0, 0.5s 지연, 다음 섹션이 위로 | 히어로 `position:sticky`, rAF로 scrollY/(높이×0.7)만큼 opacity·translateY 40px·scale 0.96. 모바일·reduced-motion은 해제 |
| 패럴랙스(Rellax) | `data-rellax-speed="1.3"` 구름 | `[data-parallax=k]` 화면 중앙 기준 거리 × k, 장식 원(blob)과 히어로 아이콘(−0.08/−0.14/−0.2) |
| 루프 애니메이션 | floatHorizontal, Rotate, arrow-hover | 히어로 원 floatY 6s(위상 −2s/−4s), 화살표 nudge 1.8s, scroll 인디케이터 선 1.6s |
| 스크롤 인디케이터 | "scroll" + 세로선 | 동일 |
| 추가(IT 회사 톤) | — | 상단 진행 바(scaleX), 숫자 카운트업 1.1s ease-out, 제목 자간 0.14em→0.02em, 키커 밑줄 그리기, 카드 호버 −6px + 아이콘 기울기 |
규칙: `prefers-reduced-motion`이면 모든 연출 해제·즉시 표시. 모바일(<1024px)은 등장만 유지하고 고정 히어로·패럴랙스·blob은 끈다. JS 실패 시에도 첫 화면은 보이도록 히어로 요소는 로드 직후 표시.

## 8. 색 통일과 기술 연출 (2026-10-03, 사장님 승인)
**색 — 파랑 한 계열 + 무채색 + 노랑 한 번.** 레퍼런스 넷을 섞으며 색 계열이 7개가 되어 "이어 붙인" 인상이었다.
- 주색 `#0099D9`, 농담: 히어로 `#2E8EDB→#EAF5FB`, 섹션 `#D5F0F6/#EEF7FB`, 원형·패널 틴트 `#DDF0FA #CFE6F7 #BFDDF4 #D6ECF8`(이전 파스텔 4색을 대체, 변수명 `--gold-l` 등은 호환용으로 유지), 사선 띠 `#BFE6F8→#5FB4E6`, 푸터 남색 `#0E2A47`.
- 무채색: 제목 `#212121`, 본문 `#575757`, 모눈 `#F0F4F8/#DDE6EF`(푸른 기).
- 노랑 `#F6DF62`은 페이지 전체에 **한 번만**(MAKOROとは). 영역 구분은 색이 아니라 번호·아이콘으로. 아이콘(Fluent Emoji)의 원색이 유일한 다색.

**기술 연출 — 라이브러리 없음, 전부 `sites/makoro/index.html` 안.**
| 연출 | 구현 | 끄는 조건 |
|---|---|---|
| WebGL 하늘 | `<canvas id="sky">` 프래그먼트 셰이더(fbm 5옥타브, 도메인 워프), 마우스에 따라 흐름 이동, 절반 해상도, 히어로가 안 보이거나 탭이 숨으면 그리지 않음 | 모바일(<1024)·reduced-motion·WebGL 실패 → CSS 구름 |
| MAKORO 글자 조립 | 글자별 span이 흩어진 위치(`--x --y --r`)에서 모임, 0.08s 간격 | reduced-motion |
| つなぐ 선 | SVG path `pathLength=1` + 스크롤 진행에 맞춘 `stroke-dashoffset`, 세 점(ANALOG·DIGITAL·AI)이 차례로 켜짐 | reduced-motion이면 완성 상태 |
| 핸들 카드 | 테두리를 배경 그라데이션 4개의 `background-size`로 그리고, 0.9s 뒤 모서리 핸들이 찍힘. 호버 시 3D 기울기(±7°) | 터치 기기는 기울기 없음 |
| 숫자 | 무작위 숫자 → 값으로 수렴 | reduced-motion |
| 모눈 커서 광원 | `.paper::after` radial-gradient를 `--mx --my`로 이동 | 터치 기기 |
- 하지 않는 것: 스크롤 가로채기, 3D 모델, 페이지 전환 — 사내 PC에서 무겁거나 스크롤이 어색하면 닫힌다.
- `<noscript>`에서 모든 연출 요소를 표시 상태로 고정(JS 실패 시에도 내용이 보인다).

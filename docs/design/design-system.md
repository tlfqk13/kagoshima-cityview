# 디자인 시스템 — 旅のしおり (여행 스크랩북)

> 상태: v1 (2026-09-21 제정)
> 레퍼런스 1번: [ひらやすみ × 杉並区](https://hirayasumi-anime.jp/suginami/). 지자체 협업 스크랩북 사이트
> 보조 레퍼런스: [佐賀市へ #連れ帰省](https://atarimae-kanko.com/tsurekisei/). 사가시 관광진흥과 공식 캠페인
> 분석 근거: [reference-analysis.md](reference-analysis.md)

이 서비스는 일본 지자체(가고시마시 관광과)에 채택되는 것을 목표로 합니다. 그래서 디자인은 **"여행자가 직접 만든 여행 수첩(旅のしおり)"**처럼 따뜻해야 하면서, 동시에 **공공 사이트로서 믿을 수 있어야** 합니다. 새 화면을 만들 때는 이 문서의 토큰과 규칙을 따릅니다.

- 토큰: [`src/styles/tokens.css`](../../src/styles/tokens.css)
- 공통 요소: [`src/styles/scrapbook.module.css`](../../src/styles/scrapbook.module.css)
- 적용 예: 랜딩 [`src/app/page.tsx`](../../src/app/page.tsx), [`src/components/home/`](../../src/components/home/)

## 1. 원칙

1. **종이 위의 정보.** 화면은 크림색 종이이고, 정보는 그 위에 붙인 사진·메모·도장으로 보여 줍니다. 유리 효과·그라디언트 버튼·네온 같은 디지털 질감은 쓰지 않습니다.
2. **장식은 가장자리에, 정보는 똑바로.** 기울기·손글씨·테이프는 틀과 장식에만 씁니다. 본문, 시간표, 정류장 이름, 요금처럼 읽어야 하는 정보는 기울이지 않고 표준 서체로 씁니다.
3. **실제 데이터가 소품이 된다.** 정류장 표지판의 시간표, 손그림 지도의 오차 거리, 노선 띠의 정류장 수는 모두 노선 JSON과 감사 데이터에서 읽습니다. 장식용 가짜 숫자는 쓰지 않습니다.
4. **캐릭터 대신 사물.** 레퍼런스 두 곳 모두 캐릭터가 주인공이지만, 우리에게는 저작권을 가진 캐릭터가 없습니다. 버스 정류장 표지판, 승차권, 우표, 폴라로이드 같은 **여행 사물**을 주인공으로 씁니다. 지어낸 마스코트는 만들지 않습니다.
5. **공공성.** 출처 표기, 운영 주체, 문의처, 접근성 기준(§8)은 장식보다 우선합니다.

## 2. 색

모든 색은 토큰으로만 씁니다. 컴포넌트에 헥스값을 직접 쓰지 않습니다(인쇄물 `/card/*`만 예외. 인쇄는 테마와 무관한 고정색을 씁니다).

| 토큰 | 라이트 | 다크 | 역할 | 대비 (라이트, 바탕 `--paper`) |
|---|---|---|---|---|
| `--paper` | `#F3EBDD` | `#1D1B18` | 페이지 바탕 (크림 종이) | — |
| `--paper-deep` | `#E8DCC4` | `#25221E` | 섹션 띠·사진 로딩 바탕 | — |
| `--card` | `#FFFDF8` | `#2A2723` | 폴라로이드·메모·카드 | — |
| `--ink` | `#1C1A18` | `#E8E4DE` | 제목·본문 | 14.7:1 |
| `--pencil` | `#5A534B` | `#B5ACA0` | 보조 본문 | 6.4:1 |
| `--text-subtle` | `#6E675E` | `#A6A094` | 캡션·메타(최소 대비) | 4.7:1 |

### 2.1 사용 규칙
- 한 섹션의 주역 포인트는 **한 가지 색**입니다. 예: 만든 이유 = `--stamp`, 노선 한 바퀴 = `--sea`.
- `--muted`(3.2:1)는 **텍스트에 쓰지 않습니다.** 테두리·비활성 아이콘에만 씁니다. 보조 글자는 `--text-subtle`을 씁니다(2026-09-21 전 화면 교체 완료).
- 순수 검정(`#000`)과 순수 흰색 바탕은 쓰지 않습니다. 종이와 먹의 톤을 유지합니다.

### 2.2 지자체 파트너 색
레퍼런스 1번의 주색(`#009B63`)은 화면에 함께 놓인 **스기나미구 로고와 같은 초록**입니다. 협업 사이트의 주색을 지자체의 색에 맞춘 것입니다. 공식 채택이 정해지면 `--partner`를 가고시마시가 지정한 색으로 바꿉니다. 그 색은 이 문서에서 추정하지 않고, 시로부터 받은 값으로 확정합니다.
- 레퍼런스의 초록 글자는 크림 바탕에서 2.96:1로 AA에 미달합니다. 그래서 **`--partner`는 24px 이상의 큰 글씨, 띠, 도장, 아이콘에만** 씁니다. 본문 링크나 작은 글씨에는 쓰지 않습니다.

## 3. 서체

기본 서체는 레퍼런스 두 곳과 같은 **Zen Maru Gothic**입니다. `next/font`로 빌드할 때 받아 같은 도메인에서 제공하므로 런타임 CDN 요청이 없고, 한 번 본 화면은 오프라인에서도 같은 서체로 보입니다([ADR 007](../adr/007-zen-maru-gothic-self-hosted.md)). 그 밖의 서체는 시스템 폰트이며, 한글처럼 글리프가 없는 글자는 다음 폰트로 글자 단위 대체됩니다.
- 외부 폰트 CDN(`fonts.googleapis.com` 링크 등)은 쓰지 않습니다. CSP가 `font-src 'self'`입니다.
- 서체를 추가할 때는 `next/font`로 자체 호스팅하고, 일본어 폰트는 `preload: false` + precache 제외 규칙(`next.config.mjs`)을 지킵니다.

| 토큰 | 스택 | 용도 |
|---|---|---|
| `--font-serif` | KCV Serif(한글=AppleMyungjo/Batang, 가나·한자=Hiragino Mincho) | 제목, 정류장 이름, 편지 |
| `--font-sans` | **Zen Maru Gothic** → Hiragino Maru/Kaku Gothic, Yu Gothic → 시스템 | 본문, UI, 라벨, 버튼 (전 화면 기본) |
| `--font-round` | = `--font-sans` | 둥근 고딕임을 명시하고 싶을 때 |
| `--font-hand` | Bradley Hand, Noteworthy, Segoe Print, Klee → 세리프 | **장식 전용** 손글씨 |
| `--font-num` | DIN Condensed, Bahnschrift Condensed | 큰 숫자·영문 대형 타이포 |
| `--font-mono` | SF Mono, Menlo | 좌표, 시각, 도메인 |

### 3.1 타입 스케일 (375px → 1440px 사이에서 선형으로 커짐)
| 토큰 | 범위 | 용도 |
|---|---|---|
| `--fs-display` | 34 → 56px | 캠페인 표제 |
| `--fs-h1` | 28 → 44px | 페이지 제목 (영어는 한 단계 작게) |
| `--fs-h2` | 24 → 40px | 섹션 제목 |
| `--fs-h3` | 19 → 22px | 카드 제목 |
| `--fs-body` | 15px | 본문 |
| `--fs-small` | 13px | 보조 본문 |
| `--fs-caption` | 12px | 캡션, 메타 (최소 크기) |

### 3.2 규칙
- 본문 행간 `--lh-body`(1.9), 제목 `--lh-heading`(1.45). 일본어 본문은 1.8~2.0을 유지합니다(두 레퍼런스 모두 1.8~2.0).
- **한국어**는 `word-break: keep-all`로 어절 단위 줄바꿈을 합니다. 일본어에는 적용하지 않습니다(띄어쓰기가 없어 줄바꿈이 사라집니다). `html[lang='ko']` 선택자로 한정합니다.
- 일본어 제목은 한 줄 20자 안팎에서 의미 단위로 `<br>`을 넣습니다. 번역 JSON의 `\n`을 줄바꿈으로 씁니다.
- 손글씨(`--font-hand`)는 **한 구절(15자 이내)** 장식에만 씁니다. 버튼, 본문, 링크, 가격, 시간에는 쓰지 않습니다.
- 12px 미만 글자는 쓰지 않습니다(인쇄물 제외).

## 4. 레이아웃

- **기준 폭:** PC 1440px, SP 375px. 두 레퍼런스가 모두 같은 기준을 씁니다.
- **전환점:** `max-width: 1023px`까지를 SP(태블릿 포함)로 봅니다. 두 레퍼런스의 공통 기준입니다. 새 컴포넌트는 `@media (max-width: 1023px)` 하나만 씁니다.
- **본문 폭:** `--content-w`(1160px). 일본어 본문 한 줄은 35~40자를 넘지 않게 텍스트 블록에 `max-width`를 둡니다.
- **여백:** 섹션 상하 `--section-y`, 좌우 `--gutter`. 간격은 8px 기반 `--space-1`~`--space-9`를 씁니다.
- **사진 비율:** 폴라로이드는 4:3 또는 3:2. 사진은 한 장 가로 1200px 안팎, JPG q70~80으로 준비합니다.

### 4.1 화면 레이어
화면의 성격에 따라 스크랩북 요소를 쓰는 정도가 다릅니다.

| 레이어 | 화면 | 쓰는 것 | 쓰지 않는 것 |
|---|---|---|---|
| **스크랩북** | 랜딩, 스토리, 정확도 감사, 다운로드 등 읽는 화면 | 모든 토큰과 공통 요소 | — |
| **기능** | 지도(`/map`), 관리자, 인쇄물(`/card`) | 색·서체·반경·간격 토큰, 대비 규칙 | 종이 결(`texture`), 기울기, 손글씨, 테이프, 등장 연출(`ScrapbookReveal`) |

지도는 현장에서 버스를 기다리며 보는 화면입니다. 장식이 정보를 가리거나 조작을 늦추면 안 됩니다. 기능 레이어에서는 종이 질감과 기울기를 쓰지 않고, 같은 색과 서체로만 톤을 맞춥니다.

## 7. 모션

| 토큰 | 값 |
|---|---|
| `--ease-out` | `cubic-bezier(0.22, 1, 0.36, 1)` (레퍼런스 공통) |
| `--dur-fast` | 0.2s. 호버 |
| `--dur-base` | 0.7s. 등장 |
| `--dur-slow` | 1.1s. 손그림 그리기 |

규칙:
- 등장은 **아래에서 떠오르며 기울기가 제자리를 찾는** 방식 하나로 통일합니다(`ScrapbookReveal`).
- 도장은 `stampIn`(2.1배 → 0.94배 → 1배), 손그림 선은 그려진 뒤 `jitter`로 미세하게 떱니다.
- 스크롤에 연동한 움직임은 **한 섹션에 하나**만 둡니다(예: 노선 띠의 버스).
- `prefers-reduced-motion: reduce`이면 모든 모션을 끕니다. 토큰 지속시간이 0이 되고, 각 컴포넌트에도 분기가 있습니다.
- 로딩 화면, 자동재생 영상, 무한 회전은 쓰지 않습니다. 레퍼런스에는 로딩 연출이 있지만, 현장에서 버스를 기다리는 사용자에게는 지연이 곧 비용입니다.

## 8. 지자체 사이트 요건 (일본)

채택 심사 때 확인될 가능성이 높은 항목입니다. 장식보다 우선합니다.

1. **웹 접근성:** 일본의 공공 웹 접근성 기준은 JIS X 8341-3(WCAG 2.0 대응)이고, 총무성 「みんなの公共サイト運用ガイドライン」은 지자체 사이트가 적합 레벨 AA 준거를 목표로 하도록 권고합니다. 채택 심사에서 확인될 수 있으므로 AA를 기준선으로 삼습니다.
   - 텍스트 대비 4.5:1 이상(큰 글씨 3:1). §2의 토큰 대비표를 기준으로 합니다.
   - 장식 이미지는 `alt=""` 또는 `aria-hidden`. 흐르는 띠·복제 요소는 스크린리더에 한 번만 읽힙니다.
   - 키보드로 모든 링크·버튼에 도달할 수 있어야 하고, 포커스 표시를 지우지 않습니다.
   - 움직이는 요소는 움직임 줄이기 설정에 따라 멈춥니다.
2. **운영 주체와 문의처 표기:** 두 레퍼런스 모두 푸터에 운영 주체를 명확히 적습니다. 사가시는 課名·주소·전화·© Saga City, 히라야스미는 © 표기와 구 공식 SNS를 둡니다. 채택 뒤에는 "運営：鹿児島市 ○○課" 같은 표기와 로고 락업(`서비스 로고 × 시 로고`)을 넣을 자리를 푸터와 히어로에 남겨 둡니다. 시 로고는 사용 허가를 받은 뒤에만 넣습니다.
3. **데이터 출처:** `データ提供：鹿児島市（原データより加工）` 표기를 유지합니다(CC BY 4.0).
4. **개인정보·쿠키:** 사가시는 쿠키 동의 배너와 개인정보 처리방침 링크를 둡니다. 우리는 폼과 회원 기능이 없지만, 채택 전에 분석 도구의 쿠키 사용 여부를 확인하고 이용약관·개인정보 페이지를 준비합니다.
5. **일본어 우선:** 기본 언어는 일본어입니다. 일본어 문구를 먼저 확정하고 영어·한국어를 맞춥니다. 행정 용어(運行・運賃・停留所・のりば 등)는 공식 표기를 따릅니다.
6. **LINE:** 일본 지자체 사이트의 공유·공식 채널에는 LINE이 기본으로 들어갑니다.

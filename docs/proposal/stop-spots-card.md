# 「降りたらここ」— 정류장별 주변 안내를 관광과·상점가와 함께 만드는 카드

> 채택 협상용 카드. **우리가 임의로 가게를 고르지 않는다**는 것이 이 카드의 핵심이다(광고 없음·공정성). 관광과·상점가 조합이 고른 곳만 싣고, 유료 게재는 하지 않는다.

## 현재 상태 (2026-09-23)
- 정류장 20곳 중 주변 안내가 있는 곳: 8곳 → 공공시설(義士碑·洞窟·顕彰館·かんまちあ 등)을 채워 **20곳 모두 최소 1건**으로 만듦(이번 커밋).
- 음식·시장 카테고리: 天文館アーケード(쇼핑)·熊襲亭(음식)·山形屋(쇼핑) 3건뿐. **먹거리·시장은 비어 있다** — 이 빈칸이 관광과·상점가에 줄 자리다.

## 상대가 얻는 것
| 상대 | 얻는 것 |
|---|---|
| 관광과 | 외국인이 정류장에서 내리는 순간 "시가 추천하는 곳"이 4개 언어로 보임. 기존 관광 사이트로 링크 가능 |
| 상점가·시장 조합 (天文館, 中央駅, 磯 등) | 시티뷰 이용객 동선 위에 상점가가 노출. 월간 리포트로 "그 정류장에서 몇 명이 열람했는지" 확인 |
| 교통국 | 정류장 안내가 풍부해져 "내릴 곳 문의" 감소 |

## 우리가 요청하는 것
1. 정류장별 추천 장소 목록(이름·도보 분·카테고리) — 관광과 또는 상점가 조합이 선정. 1정류장 3곳 이내
2. 각 장소의 공식 다국어 표기(있으면). 없으면 우리가 번역 후 확인 요청
3. 사진은 선택. 있으면 시 관광 사진 라이브러리 사용 허가

## 규칙 (제안서에 그대로 씀)
- 게재 기준은 관광과·조합의 선정. MAKORO는 선정하지 않음
- 유료 게재·광고 없음. 순서는 도보 거리순
- 영업시간·가격은 싣지 않음(변동·책임 회피). 링크로 공식 페이지에 연결
- 분기마다 목록 갱신 요청, 폐점 시 즉시 삭제
